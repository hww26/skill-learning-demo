```

```

### 使用约定

- 每次作业放在独立的 `hwXX/` 目录中，代码与报告一起提交
- 数据文件较大时不要直接推送到 GitHub，使用网盘/学校服务器链接并在 README 中注明
- 提交信息（commit message）写清楚做了什么，例如 `完成 hw01 数据清洗部分`
